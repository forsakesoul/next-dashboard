# 📝 每日A股复盘系统（个人版）

## 访问地址

```
http://localhost:3000/stock-review/daily
```

## 功能特性

### ✨ 核心功能

#### 1. 市场环境记录
- 上证指数涨跌情况
- 两市成交额
- 市场情绪描述
- 当日核心主线/题材

#### 2. 个股操作与逻辑
- 📊 **操作类型**:
  - 买入 (开仓)
  - 卖出 (止盈/损)
  - 持仓不动
  - 观察/卖飞

- 🎯 **关键数据**:
  - 股票名称/代码
  - 成交价格
  - 个股涨跌幅
  - 核心操作逻辑

- 💡 **盈亏归因分析**（核心创新）:
  - ✅ 模式内盈利（实力）- 按照自己的交易系统赚钱
  - 🍀 模式外盈利（运气）- 偶然赚钱，不可持续
  - 🛡️ 模式内亏损（成本）- 系统内的正常成本
  - ⚠️ 模式外亏损（乱做）- 违反纪律的亏损

#### 3. 账户总结
- 当日盈亏金额
- 盈亏比例
- 总资产
- **纪律性评分**（1-5星）

#### 4. 数据管理
- 💾 **本地存储** - 数据保存在浏览器localStorage
- 📅 **多日期支持** - 管理所有历史复盘记录
- 📤 **导出全部** - 下载JSON文件备份
- 📥 **导入数据** - 从JSON文件恢复数据
- 📋 **复制JSON** - 快速复制当日数据

#### 3. 数据备份

- **导入数据**: 从JSON文件恢复数据

## 盈亏归因详解

### 为什么要归因？
传统复盘只记录"赚了多少、亏了多少"，但**不知道为什么赚、为什么亏**。归因分析帮助你：
- 识别可复制的盈利模式
- 避免不可持续的运气盈利
- 区分正常成本和纪律问题
- 长期提升交易胜率

### 四种归因类型

#### ✅ 模式内盈利（MODE_WIN）
- **定义**: 按照自己的交易系统获得的利润
- **示例**:
  - "突破30日均线+放量 → 买入 → 获利"
  - "跌破止损线 → 卖出 → 避免更大亏损"
- **意义**: 这是你的**真实实力**，可持续、可复制

#### 🍀 模式外盈利（LUCK_WIN）
- **定义**: 偶然赚到的钱，不在交易系统内
- **示例**:
  - "凭感觉追涨停板 → 碰巧赚钱"
  - "卖飞的股票继续暴涨 → 但这次止损了"
- **意义**: 这是**运气**，不要当成实力，下次可能亏

#### 🛡️ 模式内亏损（MODE_LOSS）
- **定义**: 系统内的正常成本
- **示例**:
  - "突破买入 → 假突破 → 止损离场"（系统内的试错成本）
  - "打板买入 → 第二天低开 → 按计划止损"
- **意义**: 这是**必要成本**，只要胜率>50%就是赚的

#### ⚠️ 模式外亏损（DISCIPLINE_LOSS）
- **定义**: 违反纪律导致的亏损
- **示例**:
  - "破位不止损 → 扛单 → 越亏越多"
  - "计划买A股，冲动买了B股 → 亏损"
- **意义**: 这是**纪律问题**，必须杜绝

### 长期目标
- ✅ 增加"模式内盈利"的频率和幅度
- 🍀 减少"模式外盈利"的诱惑（不要被运气迷惑）
- 🛡️ 接受"模式内亏损"（正常成本）
- ⚠️ **杜绝**"模式外亏损"（纪律红线）

## 最佳实践

### 每日复盘流程
1. **收盘后30分钟内完成** - 趁记忆清晰
2. **诚实记录** - 不要美化或隐瞒
3. **归因分析** - 每笔交易都要选择归因类型
4. **纪律评分** - 1-5星，诚实打分

### 周度复盘
1. 查看本周所有记录
2. 统计四种归因的占比
3. 识别问题：
   - 模式外盈利占比高 → 说明你在靠运气赚钱
   - 模式外亏损频繁 → 纪律性需要加强

### 月度复盘
1. 导出全月数据
2. 用Excel/Python分析
3. 计算关键指标：
   - 模式内胜率
   - 平均盈亏比
   - 纪律性得分趋势

## 常见问题

### Q1: 数据会丢失吗？
**A**: 只要不清除浏览器数据就不会丢失。但**强烈建议定期导出备份**。

### Q2: 可以在手机上用吗？
**A**: 可以！页面完美适配移动设备，手机浏览器访问即可。

### Q3: JSON文件怎么分析？
**A**: 可以用Python的pandas库，或者导入Excel分析。

### Q4: 归因类型怎么选？
**A**: 诚实地问自己：
- 这笔交易是按计划做的吗？ → 是 = 模式内
- 赚钱了吗？ → 是 = 盈利，否 = 亏损
- 组合即可：模式内+盈利 = MODE_WIN

### Q5: 可以修改历史记录吗？
**A**: 可以！选择对应日期，修改后再次点击"保存复盘"即可更新。

### Q6: 可以分享给朋友吗？
**A**: 可以导出JSON文件分享，朋友导入即可查看你的数据。
